# PassForge — что делать с этими файлами

## Коротко

Скопировать все 6 файлов в корень репозитория с заменой, удалить 4 старых файла, запушить.

---

## 1. Заменить (просто копировать поверх)

| Файл | Что делает |
|---|---|
| `index.html` | новая разметка |
| `style.css` | стили + индикатор стойкости |
| `main.js` | генератор целиком переписан |
| `logo.webp` | логотип, 3.6 КБ вместо 1.2 МБ |
| `og-image.png` | превью для соцсетей и мессенджеров, 1200×630 |
| `apple-touch-icon.png` | иконка для iOS |

`favicon.ico` оставить как есть.

## 2. Удалить из репозитория

```
script.js          не подключён, содержит битый код (getElementById('lengthSlider') → null)
slider-visual.js   не подключён, дублирует логику
logo_embed.svg     8.4 МБ, нигде не используется
logo_clean_bg.png  1.2 МБ, заменён на logo.webp
```

`logo.png` (1.1 МБ) можно оставить как исходник — на странице он не грузится.

Командой:

```bash
git rm script.js slider-visual.js logo_embed.svg logo_clean_bg.png
```

## 3. Проверить локально до пуша

```bash
cd путь/к/репозиторию
python3 -m http.server 8000
```

Открыть `http://localhost:8000` и пройти:

- [ ] Random → Generate: 16 символов, под полем появилась шкала и «~103 bit»
- [ ] Memorable → 5 слов через дефис, ~44 bit
- [ ] PIN → 6 цифр, тумблер «Easy-to-remember pattern» **выключен**
- [ ] 🌐 RU → интерфейс на русском, **и после этого переключение типов всё ещё работает**
- [ ] Copy → кнопка меняется на «Copied», пароль вставляется
- [ ] Узкое окно (~390px) → нет горизонтальной прокрутки

Последние два пункта — те, что были сломаны в текущей версии.

## 4. Аналитика — решение за вами

Прежняя конфигурация:

```js
ym(104216514, 'init', { webvisor: true, clickmap: true, ... });
```

Вебвизор записывает изменения DOM и отправляет на серверы Яндекса. Пароль находится в DOM (`#password`), то есть мог уезжать вместе с записью сессии — при заявленном на странице «no tracking».

В новом `index.html` **вся аналитика отключена**. В конце файла лежит комментарий с двумя вариантами:

- **A (рекомендую)** — Plausible или Cloudflare Web Analytics: без cookies, баннер согласия не нужен, заявление о приватности остаётся правдой.
- **B** — вернуть GA/Метрику, но тогда нужен cookie-баннер с opt-in (домен кипрский → GDPR + ePrivacy), `webvisor: false`, `clickmap: false` и правка текста «No tracking».

На `#password` уже проставлен класс `ym-hide-content` — если Метрика вернётся, содержимое поля не попадёт в запись.

## 5. Что изменилось в генерации

| | Было | Стало |
|---|---|---|
| Источник случайности | `Math.random()` (xorshift128+, предсказуем) | `crypto.getRandomValues()` + rejection sampling |
| Гарантия классов символов | нет | есть, проверено на 200 прогонах |
| Memorable, энтропия | ~27 бит (10 слогов) | ~44 бита (466 слов) |
| «Use full words» | 13 бит — хуже, чем без опции | опция убрана, словарь один |
| Simplified PIN | включён молча, ~3000 вариантов | выключен по умолчанию, помечен как небезопасный |
| Simplified PIN, длина >6 | возвращал 6 символов | возвращает запрошенную длину |
| Переключение типов в RU | не работало | работает (`data-type` вместо текста кнопки) |
| Индикатор стойкости | нет | биты энтропии + оценка времени перебора |
| Копирование | `alert()` | инлайн-фидбек + автоочистка буфера через 60 с |

Проверено автотестами в headless Chromium: 33/33.

## 6. Что осталось на потом

**Словарь.** Сейчас 466 слов = 8.9 бита на слово. Полный EFF large wordlist (7776 слов) даёт 12.9 бита. Скачать `eff_large_wordlist.txt` с eff.org/dice, положить рядом как `wordlist.json` и подгружать вместо константы `WORDLIST` в `main.js`. Даст ~65 бит на 5 слов вместо 44.

**Русская версия для поиска.** Перевод живёт только в JS, отдельного URL нет — для Google сайт одноязычный, весь русскоязычный трафик проходит мимо. Нужна реальная страница `/ru/`, после чего раскомментировать блок `hreflang` в `<head>`.

**Шрифт локально.** Poppins грузится с серверов Google (render-blocking + передача IP). Положить `.woff2` рядом и подключить через `@font-face`.

**Проверка по HIBP.** k-anonymity API: отправляются только первые 5 символов SHA-1, приватность сохраняется. Хорошо ложится в позиционирование и даёт повод возвращаться на сайт.
